# Shorts для TikTok (папка `контент/`)

Формат роликов утверждён — **не менять его без явной просьбы**. От пользователя приходят только
тексты, названия и описания; всё остальное уже зашито в `контент/make_shorts.py`.

## Как собрать новую партию

1. Создать `контент/тексты/<название_папки>.txt`, по строке на ролик:
   `NN | название до 60 символов | текст на экране`
   В тексте `||` — новый абзац, `|` — новая строка. Образец — `контент/тексты/неделя_19-25.txt`.
2. `cd контент && python3 make_shorts.py тексты/<название_папки>.txt`
   → ролики `01.mp4 …` и `описания.txt` в `контент/<название_папки>/`.
3. Проверка: кадры каждого ролика (0,5 с / середина / последняя секунда) — ник и «Пиши ХОЧУ» видны;
   `grep -ciE "банк|сч[её]т" описания.txt` даёт 0.
4. Закоммитить и запушить. Из облачной сессии видео на Google Диск не загрузить — дать пользователю
   ссылку на архив ветки на GitHub, он перетащит mp4 в папку на Диске сам. `описания.txt` можно
   залить на Диск через коннектор Google Drive (textContent).

## Формат (зафиксирован, как v1 / эталон 01_short)

- 1080×1920, 30 fps, H.264 + AAC, **4,5–6 с** (текст 2,5–4 с по числу слов + концовка 2 с) —
  короткие, чтобы досматривали до «ХОЧУ».
- Фон — ролики из `контент/фоны` на весь экран (горизонтальные обрезаются по бокам), затемнение 55 %,
  без эффектов и без сгенерированных картинок. По кругу: ночная дорога → ночной город → купюры →
  тёмный ролик → стол с купюрами.
- Текст Helvetica Neue Medium 50 (на Linux — клон FreeSans), белый, мягкая тень, по центру,
  виден с первого кадра, весь текст одним блоком.
- Ник `@markovvv2` 40 px сверху (y≈300) весь ролик.
- Концовка без плашки: «Пиши ХОЧУ» 80, «→ @markovvv2» 66, «расскажу, как забрать / деньги от б@нков» 44.
- Музыка — энергичные треки из `контент/музыка`, громкость выровнена, затухание в конце.

## Описания (`описания.txt`)

Для каждого ролика: `NN | название`, затем одна строка описания, одинаковая у всех:
`Пиши «ХОЧУ» в ТГ: @markovvv2. Канал с гайдом: markovrko. Доступ только у тебя, вложений ноль. #рко #заработок #подработка #студент #деньги`

## Запреты

- На экране и в описаниях нет слов «банк» и «счёт/счет» (TikTok банит) — если без них никак, «б@нк».
- Сумм за РКО нигде не писать.

## Публикация через Metricool (когда пользователь просит)

Бренд `tg.markovrko` (blogId 7424563), часовой пояс Europe/Moscow, сети TikTok + YouTube Shorts + Instagram Reels.
По 3 ролика в день в 10:00, 15:00, 18:00 по порядку номеров. Видео — ссылка на файл в Google Drive
(`https://drive.google.com/file/d/<id>/view`), Metricool сам его забирает. Текст поста:
`<название>\n<описание>`; `tiktokData.title` и `youtubeData.title` = название, YouTube `type: short`,
`madeForKids: false`, теги `рко, заработок, подработка, студент, деньги`; Instagram —
`instagramData: {type: "REEL", showReelOnFeed: true}`. Перед постановкой проверить
`getScheduledPosts`, чтобы не задвоить.
