# Бот «Озарение» (@Ozarenieebot)

Воронка для фрилансеров: курс → 3 вопроса → ответ на боль → видео → запись на разбор → заявка тебе в личку.
Если человек остановился, бот сам напоминает (через час, через сутки и т.д.).

## Как устроено

| Этап | Что видит человек |
|---|---|
| /start | Ссылка на курс и кнопка «Курс у меня» |
| Вопросы | Сфера, доход, что мешает (кнопками) |
| Ответ | Текст под его боль + вопрос «сколько ты на этом теряешь» |
| Видео | Видео со схемой и кнопка «Записаться на разбор» |
| Запись | Номер или ник → удобное время → заявка уходит админу |

Все тексты лежат в `texts.py`. Меняй их там, код трогать не нужно.

## Запуск

1. **Новый токен.** Старый токен лежал в открытом коде, его мог взять кто угодно.
   В @BotFather: `/mybots` → бот → `API Token` → `Revoke current token`.
2. Узнай свой Telegram ID у @userinfobot.
3. Задай переменные окружения (образец в `.env.example`):
   - `BOT_TOKEN` токен бота
   - `ADMIN_IDS` твой ID (сюда придут заявки)
   - `COURSE_URL` ссылка на платформу с курсом
   - `VIDEO_FILE_ID` или `VIDEO_URL` видео
   - `DB_PATH` путь к базе на постоянном диске хостинга (например `/data/bot.db`), иначе после перезапуска база обнулится
4. Запусти: `docker build -t ozarenie . && docker run --env-file .env ozarenie`
   или `pip install -r requirements.txt && python bot.py`.

**Как получить VIDEO_FILE_ID:** запусти бота, отправь ему видео со своего (админского) аккаунта. Бот ответит file_id.

## Команды админа

- `/stats` сколько людей на каждом этапе
- `/leads` последние 15 заявок
- `/broadcast текст` рассылка всем
- Ответь (reply) на заявку или сообщение человека, бот перешлёт ему твой ответ.

Текст поста для канала лежит в `post.md`.
